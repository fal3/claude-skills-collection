# Prompt scenarios

## Should activate

- "Migrate this Xcode project to Swift 6 strict concurrency target by target."
- "Why does this Swift 6 build say sending `self` risks causing data races?"
- "Enable approachable concurrency and choose default actor isolation for my app and package targets."
- "Replace this DispatchGroup workflow with structured concurrency and cancellation."
- "Bridge this repeating Objective-C delegate into an AsyncSequence without races."
- "Review these actors and Sendable types before switching the target to Swift 6 mode."

## Should not activate

- "Explain how Swift optionals work."
- "My SwiftUI list scrolls slowly; profile it before suggesting changes."
- "Show the parameters for URLSession's data task."
- "Add a synchronous computed property to this value type."
- "Explain a Core Data migration failure that has no concurrency diagnostic."
