- "Expose my project-completion use case with AppIntent, AppEntity, search, and App Shortcuts."
- "Inject the same actor-backed service into an EntityQuery and intent without using a UI singleton."
- "Build an App Group-backed timeline widget and explain when to reload it."
- "Choose between an interactive widget, Control Widget, and Live Activity for this workflow."
- "Add confirmation and lock-screen privacy rules to this destructive intent."
- "Open the app at the selected entity after a shortcut, with a missing-entity fallback."
- "Evaluate an OS 27 beta App Intents schema while retaining an Xcode 26 stable path."

## Should not activate

- "Add an ordinary button inside my app's settings screen."
- "Fix spacing in this SwiftUI VStack."
- "Schedule a BGProcessingTask that has no widget or App Intent surface."
- "Implement the APNs server for an existing Live Activity; the client code is already complete."
- "Explain a generic URL parser unrelated to system actions or handoff."
