# Prompt scenarios

## Should activate

- "Build a SwiftUI toolbar for iOS 17 and macOS 14, and explain any platform-specific placements."
- "Show view-owned and injected `@Observable` models, including the correct `@State` and `@Bindable` usage."
- "Create state-driven `NavigationStack` routes with restoration-friendly values."
- "Design a form that supports accessibility Dynamic Type sizes without truncating user content."
- "Review this `List` for identity and performance problems, but recommend changes only after explaining what to measure."
- "Use an SF Symbol introduced after my deployment target and provide a verified fallback."

## Should not activate

- "Implement this screen entirely in UIKit."
- "Design a platform-neutral color palette with no SwiftUI implementation."
- "Diagnose a Core Data migration that has no SwiftUI surface."
