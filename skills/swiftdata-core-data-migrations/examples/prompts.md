# Prompt scenarios

## Should activate

- "Add a nonoptional field to my released SwiftData model without losing existing rows."
- "Build complete V1, V2, and V3 VersionedSchema snapshots and a SchemaMigrationPlan."
- "My `didMigrate` closure cannot fetch the old SwiftData model. Design a safe intermediate version."
- "Decide whether this Core Data entity split can be lightweight or needs a mapping model."
- "Plan gradual SwiftData adoption in an existing Core Data app without sharing managed objects."
- "Test this CloudKit-backed migration against a copied production store and define recovery."

## Should not activate

- "Write a SwiftData predicate for reminders due today."
- "Explain how `@Query` updates a SwiftUI view."
- "Encode this value to JSON with Codable."
- "Move a CSV file to a new directory."
- "Replace Core Data because SwiftData is newer."
