# Prompt scenarios

## Should activate

- "Audit this checkout flow with VoiceOver and explain labels, values, hints, order, and focus recovery."
- "Make this card accessible without combining its two buttons into one element."
- "Adapt this layout through all Dynamic Type sizes without truncating user content."
- "Review this custom control for Voice Control, Switch Control, and Full Keyboard Access."
- "Provide Reduce Motion and Differentiate Without Color alternatives for this animation."
- "Design an iOS 26 Assistive Access scene and keep an iOS 17 fallback."

## Should not activate

- "Change this brand color without an accessibility requirement."
- "Debug this unrelated launch crash."
- "Audit the semantics of a platform-neutral web page."
